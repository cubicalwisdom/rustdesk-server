# Official Client Custom ID Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Enable the stock RustDesk client's official Change ID request against the RCGK OSS `hbbs` server.

**Architecture:** Add a transactional SQLite peer rename, expose it through `PeerMap` so the database and live peer map move together, and wire the existing TCP `RegisterPk` request to that operation. Preserve all non-ID peer fields and return RustDesk's existing protocol result codes.

**Tech Stack:** Rust, Tokio, SQLx SQLite, RustDesk rendezvous protobuf, Docker-based Cargo verification, GitHub Actions ARM64 build.
